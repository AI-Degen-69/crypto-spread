# Dynamic Symmetric Mid-Anchored Quoting & Unified Stop-Loss Strategy

## Problem Statement
איך נוכל לאפשר לבוט המסחר תמחור דינמי וסימטרי מתוך ה-Mid החי של כל רגל בפתיחת חלון (כדי לסחור בשווקים שנפתחים ב-30/70, 50/51 או בכל הטיה בסיכון זהה ובמרחק שווה מכל הוראה), בשילוב עם מנגנון Stop Loss Trigger יחיד וחד-משמעי של 0.05$ המבטל מיידית את הפקודה הממתינה בצד השני?

## Recommended Direction
**תמחור דינמי וסימטרי מלא מתוך ה-Mid החי של כל רגל בפתיחת חלון:**
1. **חישוב הוראות לימיט בפתיחה**:
   $$\text{BUY\_UP} = \text{round}(\max(0.01, \min(0.99, \text{UP\_MID} - \text{Offset})), 3)$$
   $$\text{BUY\_DN} = \text{round}(\max(0.01, \min(0.99, \text{DN\_MID} - \text{Offset})), 3)$$
2. **סימטריה מלאה בהזדמנות להתמלאות**:
   כל רגל מקבלת בדיוק את אותו מרחק ה-Offset (למשל 2¢) מה-Mid או ה-Best Ask שלה.
   * **דוגמת 50/51** (Mid UP = 0.51, Mid DN = 0.50):
     * הוראת UP: $0.51 - 0.02 = 0.49$ (מרחק 2¢)
     * הוראת DN: $0.50 - 0.02 = 0.48$ (מרחק 2¢)
     * עלות זוג: $0.49 + 0.48 = 0.97$$ (רווח נעול בפדיון: $0.03$$ / 3¢).
   * **דוגמת 30/71** (Mid UP = 0.30, Mid DN = 0.71):
     * הוראת UP: $0.30 - 0.02 = 0.28$ (מרחק 2¢)
     * הוראת DN: $0.71 - 0.02 = 0.69$ (מרחק 2¢)
     * עלות זוג: $0.28 + 0.69 = 0.97$$ (רווח נעול בפדיון: $0.03$$ / 3¢).
3. **Stop Loss Trigger יחיד וחד-משמעי של 0.05$**:
   * פוזיציה בודדת שנסחפת ב-0.05$ לרעתה מופעל לגביה Stop Loss Trigger מיידי.
   * תווית הפרמטר ב-Cockpit/UI עודכנה במפורש ל-`Stop Loss Trigger ($)` לבהירות מלאה.
   * ברגע שהסטופ לוס מופעל בצד אחד, הפקודה הממתינה בצד השני מתבטלת מיידית (`CANCELLED`).
4. **זוג משולב (Paired Position)**:
   * אינו מופעל עליו סטופ לוס. ברגע ששני הצדדים נתפסים, מבוצע `PAIR_MERGE` לנעילת רווח הספרד ב-$1.00 נקי מול Polymarket.
