🕹️ בדיקה ידנית ב-2 צעדים (לראות בעיניים)

  1. פתחו את הדשבורד ב-http://127.0.0.1:8802 → בטאב Live חפשו את שורת ה-provenance מתחת ל-“Window Capture Targets” (קובץ מקור · לפני X דקות · N חלונות סגורים) ואת כפתור Rebuild Stats ב-header. לחצו עליו וראו שהבאדג' מתעדכן — לחיצה כפולה לא מריצה פעמיים.
