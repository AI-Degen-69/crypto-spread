💡 במילים פשוטות: מה השתנה?

לפני: כמו לצלם תמונת סטילס אחת בשנייה ואז לנסות להבין מה קרה במשחק כדורגל. אם שלושה גולים נכנסו בין צילום לצילום — הם פשוט לא קיימים בשבילך.

אחרי: הבוט מחובר עכשיו לשידור חי. כל עסקה שנסגרת בבורסה מגיעה אליו ברגע שהיא קורית, ולא רק אם היא במקרה נמצאה בתמונה הבאה.

למה אכפת לנו: מנוע הבדיקה־לאחור מכריע אם הצעה שלנו הייתה מתמלאת לפי עסקאות אמיתיות שנרשמו במחיר שלנו. בלי הזנה מלאה — 0 מילויים במאות חלונות, כלומר אי אפשר לדעת אם האסטרטגיה עובדת.

🟢 אחרי השינוי:

  • חיבור קבוע לערוץ השוק של הבורסה שרואה כל עסקה מיד.
  • HTTP נשאר רק כרשת ביטחון לשניות שבהן הערוץ שתק — לכל רגל בנפרד.
  • מנגנון מניעת כפילויות בין שני המקורות: עסקה לא תיספר פעמיים ולא תייצר מילוי כפול.
  • מדדי בריאות גלויים בקובץ הסטטוס: מחובר/מנותק, ניתוקים, וכמה עסקאות מכל מקור.
  • דגל --no-ws מחזיר להתנהגות הישנה בשנייה, אם צריך.

⚡ זרימת התהליך החדש

01 · קלט / טריגר

חיבור קבוע לבורסה

חוט רקע פותח חיבור לערוץ השוק, נרשם לטוקנים של החלונות הפעילים, ושולח אות חיים כל 10 שניות. ניתוק מוביל לחיבור מחדש עם השהיה מתארכת עד 30 שניות.

02 · עיבוד ולוגיקה

חציצה ואימות

כל עסקה נבדקת (מחיר בטווח 0–1, גודל חיובי, ללא ערכים לא-סופיים) ונכנסת למאגר מוגן-נעילה. מחליפים חלון? המאגר של הטוקן הישן משוחרר מיד.

03 · תוצאה מאומתת

כתיבה לקובץ הנתונים

כל שנייה הקולט שואב את מה שהצטבר, מסנן כפילויות מול HTTP, וכותב לקובץ היומי — הקובץ שמנוע הבדיקה-לאחור קורא כדי להחליט על מילויים.

🕹️ מדריך בדיקה ידנית (Touch & See)

שלוש בדיקות שמוכיחות את השינוי בעיניים, ישירות מהטרמינל:

1. לוודא שהערוץ נדלק בהפעלה

הרצה בודדת של הקולט לתיקייה זמנית:

python -m scripts.collect_ticks --once --out run/ticks-check
מה אמורים לראות: שורת הפתיחה מסתיימת ב-ws=on, ובסופה שורת סיכום עם ws_trades=. זו ההוכחה שהערוץ החדש נדלק ולא נפל חזרה ל-HTTP.

2. להריץ דקה מול השוק החי ולקרוא את מדדי הבריאות

מפעילים את הקולט, נותנים לו לרוץ כדקה, עוצרים עם Ctrl+C, ואז קוראים את קובץ הסטטוס:

python -m scripts.collect_ticks --out run/ticks-check
Get-Content run/ticks-check/manifest.json
מה אמורים לראות: "ws_connected": true, "ws_reconnects": 0, ו-"tape_captured_ws" עם מספר שגדל — עסקאות שנקלטו מהערוץ החדש ולא היו נראות קודם. "tape_empty_rate" אמור לשבת הרבה מתחת ל-0.98 הישן.

3. להשוות מול ההתנהגות הישנה

אותה ריצה בדיוק, רק עם הדגל שמכבה את הערוץ:

python -m scripts.collect_ticks --once --no-ws --out run/ticks-legacy
מה אמורים לראות: שורת הפתיחה מציגה ws=off, וב-manifest.json של התיקייה הזו "ws_enabled": false ו-"tape_captured_ws": 0 — בדיוק ההתנהגות הישנה, זמינה בלחיצה אחת אם הבורסה נופלת.
