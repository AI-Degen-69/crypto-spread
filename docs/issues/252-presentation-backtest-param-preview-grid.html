💡 במילים פשוטות: מה השתנה?

עד היום, כיוונון אסטרטגיית הבקטסט היה כמו ניווט מטוס בעלטה מוחלטת: ראינו רשימה של שדות מספרים יבשים (Offset, Stop, Delay), והיינו צריכים לנחש בראש איפה יעמדו הפקודות או להמתין לבקטסט ארוך כדי לגלות שסכומי העיכוב וה-Dead Zone חסמו את כל חלון הציטוט. עכשיו, נוסף מכ״ם ויזואלי 2D חי שמשרטט במדויק את המפה הגאומטרית כולה תוך כדי הקלדה או גרירת הסליידרים — בדיוק איפה המיד ($0.50), איפה רגלי הלונג והשורט, מתי הסטופ ייפדה, וכמה שניות פעילות נשארו בתוך החלון.

🎮 נסו כאן — סימולטור הגריד האינטראקטיבי החי

הזיזו את הסליידרים להלן כדי לראות את אלגוריתם ה-SVG של הדשבורד מחשב ומשרטט את הגאומטריה בזמן אמת:

🔄 לפני מול אחרי

🔴 לפני השינוי:

  • שדות קלט מספריים מבודדים ומנותקים ללא פידבק ויזואלי הדדי.
  • חסימות שחלון הציטוט סובל מהן (כגון Delay + Dead Zone ≥ 300s) התגלו רק כבקטסט ריק עם 0 טריידים.
  • חוסר יכולת להעריך מיידית את יחס המחירים: מרווח (Spread Width), עלות הזוג (Pair Cost), ומרחק הסטופ באגורות.
  • ערכי 0 בשדות פרמטרים היו עלולים להידרס בשל המרות falsy לא מוגנות.

🟢 אחרי השינוי:

  • גריד וקטורי 2D מלא (SVG רספונסיבי ב-ViewBox 760×260) המוטמע ישירות ב-DOM של כרטיסיית הבקטסט.
  • עדכון ריאקטיבי מיידי (<16ms) בכל שינוי קלט (`input`/`change`) או איפוס פרמטרים.
  • תגיות סיכום (Pill Badges) צבעוניות: רוחב מרווח ב-¢, עלות זוג מול תקרה, מרחק סטופ באגורות, ושניות פעילות באחוזים.
  • מנגנון חילוץ מוגן readFinite המשמר במדויק ערכי 0 תקינים ללא דריסת ברירת מחדל.
  • אפס תלויות npm, אפס קריאות רשת, ותאימות מלאה ל-Dark Mode ולתקני נגישות.

⚡ זרימת התהליך והארכיטקטורה

01 · קלט ואירועים ריאקטיביים

מאזיני אירועים ב-SPA

פונקציית setupBacktestInputListeners() מאזינה לאירועי input ו-change בכל בקרי הטופס (offset, stop, delay, dead zone, pair cost), ומפעילה את הרינדור מיד בכל הקלדה, גרירה או איפוס.

02 · חילוץ מוגן וחישוב גאומטרי

readFinite ומיפוי קואורדינטות

פונקציית העזר מחלצת ערכים מספריים מדויקים ושומרת אפסים תקינים. מחושבים קואורדינטות הזמן (0s–300s) וגובה המחיר ($0.00–$1.00), יחד עם בדיקת חסימת חלון (Delay + Dead ≥ 300s).

03 · שרטוט וקטורי וסנכרון תגיות

רינדור SVG ו-Pill Badges

הקוד מייצר אלמנטי SVG טהורים (שנתות רשת, אזורי הצללה של Delay ו-Dead Zone, קווי הזמנות לונג ושורט, קו סטופ וריוורסל) ומעדכן תגיות סיכום צבעוניות בלחיצה אחת וללא פניות רשת.

🕹️ מדריך בדיקה ידנית (Touch & See)

בדיקה פשוטה להוכחת השינוי בעיניים בדשבורד האמיתי ללא הרצת טסטים:

1. הפעלת שרת הדשבורד המקומי

python -m uvicorn server.osc_dash:app --host 127.0.0.1 --port 8802

2. ניווט לטאב הבקטסט

http://127.0.0.1:8802  →  לחיצה על כרטיסיית Backtest בראש העמוד
מה אמורים לראות: בתוך כרטיסיית "Backtest Parameters" מופיע גריד SVG מהודר בגווני שחור-ציאן עם תגיות סיכום עליונות, ציר מחיר ($0.00-$1.00), ציר זמן (0s-300s), קו Mid זהב ב-$0.50, קווי פקודות ורצועת ציטוט.

3. בדיקת ריאקטיביות מיידית

שנו את ערך Spread Offset מ-0.02 ל-0.05.

מה אמורים לראות: תוך כדי הקלדה, ללא רענון עמוד וללא שום קריאת רשת, קווי ה-Long Bid וה-Short Complement מתרחקים זה מזה, תגית המרווח מתעדכנת מיד ל-10.0¢, ועלות הזוג מחושבת מחדש.

4. בדיקת התרעת חסימת חלון

הזינו ב-Entry Delay ערך של 200 וב-Dead Zone ערך של 150 (סך הכל 350s > 300s).

מה אמורים לראות: מרכז הגריד נצבע באדום ומופיעה התרעה ויזואלית ברורה: ⚠️ Quoting Window Blocked (Delay + Dead Zone ≥ Window Duration).

📁 קבצים שהשתתפו בשינוי

קובץתפקיד והשפעה
server/osc_dash.py הטמעת אלמנט #btParamPreviewWrap ו-#btParamPreviewSvg, סגנונות CSS, פונקציית updateBacktestParamPreview(), רישום מאזיני אירועים, ופונקציית readFinite לשימור אפסים.
tests/test_osc_dash_integration.py בדיקות אינטגרציה מלאות: אימות קיום אלמנטים וסגנונות ב-SPA, בדיקת הרצת Node.js מול חישובי הגאומטריה של ה-SVG, ואימות היעדר קריאות רשת.
