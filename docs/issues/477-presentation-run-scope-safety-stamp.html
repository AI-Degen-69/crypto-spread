What changed

Your safety stamp now checks your run — not last month's list

Every test run ends with a safety stamp: did the replay use the exact settings the live run used? Before, the stamp always checked the same old three-item list — even when your run used something new. It said "all good" while looking the other way. Now it checks exactly what your run used.
